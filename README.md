# Ojas Mithra

Bio-enzyme cleaning essentials and Ayurvedic preparations, made by hand in rural south India.

A Next.js 16 (App Router) + TypeScript site with GSAP and Lenis for motion.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # typecheck, lint, formatting
npm run build && npm run start
```

See [CLAUDE.md](./CLAUDE.md) for the architecture, conventions and how the home → product animation works.
